# Apple Leaf Disease Detection

## Project Overview
CNN-based system for detecting apple leaf diseases (Apple Scab, Black Rot, Cedar Apple Rust, Healthy).

## Files
- `main.py` - Streamlit web application
- `train.ipynb` - Model training code
- `test.ipynb` - Model testing code
- `trained_plant_disease_model.keras` - Trained model

## How to Run
```bash
pip install -r requirements.txt
streamlit run main.py
